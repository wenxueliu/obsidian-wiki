# Default Layout Routing

- 可复用的抽象知识归类为 `concept`。
- 具体人物、组织、产品或其他有稳定身份的对象归类为 `entity`。
- 可重复执行的操作过程、调试方法或工具用法归类为 `skill`。
- 对外部材料的描述或尚未形成稳定抽象的内容归类为 `reference`。
- 跨多个页面形成的新结论归类为 `synthesis`。
- 按日期记录的活动归类为 `journal`。
- 只服务于单个项目的内容使用对应的 `project_*` 类型；项目入口使用 `project_overview`。
- 无法可靠判断时选择 `reference`。不得自行创造 page type 或目标目录。
