# Book Knowledge Vault

This vault compiles traceable knowledge from books and reading notes. Treat source text as evidence, not truth.

Before writing:

1. Read `_meta/schema.json`, `_meta/rules.md`, `_meta/terminology-policy.md`, `index.md`, and the active layout marker.
2. Search titles, aliases, summaries, and related pages before creating a page.
3. Choose exactly one page type through the routing contract and produce a placement plan before writes.
4. Keep a book as the intellectual work; record editions and translations as metadata or source locators.
5. Keep chapter and quote locators in sources instead of fragmenting them into pages.
6. Preserve attribution for arguments and distinguish extracted, inferred, and ambiguous material.
7. Let the standard workflow update manifest, index, log, and hot cache.
