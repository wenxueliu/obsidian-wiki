# Terminology Policy

- Use `book` for an intellectual work, `edition` for a publication variant, and `reading_note` for a dated encounter.
- Use `argument` for an attributed claim and `concept` for an abstract idea that can stand independently.
- Use `theme` for a recurring motif within or across works.
- Use `person` for a human identity; `author` is a contextual role routed to the same page.
- Preserve original titles and names in `title` or `aliases`; do not silently translate identities.
